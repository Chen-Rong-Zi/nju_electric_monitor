### 统计卡片

4 列网格，响应式（2 列 → 1 列）：
- **当前电量**：最新一条记录的值，单位 "度"
- **今日用电量**：当天最早记录 - 当天最晚记录
- **本周用电量**：本周初值 - 本周末值
- **日均用电量**：总消耗量 ÷ 监测天数

### 用电预测

- 取近 7 天的日均用电量
- 公式：当前余额 ÷ 日均用电量 = 剩余天数
- 最后记录时间 + 剩余天数 = 预计用完时间
- 显示具体日期和时刻（如 "2026-08-14 (周五) 18:00 左右用完"）

### 图表

所有图表使用 Plotly.js（CDN），包含时间范围选择器：

**电量变化曲线图（余额曲线）：**
- X 轴：时间，Y 轴：剩余电量（度）
- 青色线条 + 数据点标记
- 时间范围切换：7天 / 30天 / 90天 / 全部
- 悬停显示详细数据

**每日用电量柱状图：**
- X 轴：日期，Y 轴：用电量（度）
- 绿色柱状图
- 时间范围切换：7天 / 30天 / 90天 / 全部
- 悬停显示具体数值

**24 小时用电分布图：**
- X 轴：小时（0-23），Y 轴：平均用电量（度）
- 橙色柱状图，高峰时段高亮
- 展示一天中各小时的平均用电量

### 数据计算方法

所有统计基于相邻两次记录的差值计算用电量：

1. 将数据按时间正序排列
2. 对每对相邻记录计算电量差值：`diff = prev - current`（正值 = 消耗，负值 = 充值）
3. **充值处理**：`diff < 0` 的记录视为充值事件，跳过不计入用电量统计
4. 各统计项的计算方式：
   - **今日用电量**：当天第一条和最后一条记录的电量差值（过滤充值）
   - **本周用电量**：本周最早和最晚记录的电量差值（过滤充值）
   - **日均用电量**：总消耗量 ÷ 监测天数
   - **24h 分布**：将每条用量差值按发生时间的小时分组，计算各小时平均用电量
   - **高峰日**：将每条用量差值按星期分组，计算各天平均用电量

### 时区

所有日期边界计算使用 Asia/Shanghai 时区（北京时间）。数据文件中的时间戳为 UTC，前端解析时转换为北京时间。

- **高峰时段**：统计各小时段平均用电量，找出用电量最高的时段
- **高峰日**：统计一周中各天的平均用电量，找出用电量最高的日子
- 数据来源：所有历史记录中连续两次采集的差值

### 数据表格

- 按时间倒序排列
- 列：日期、时刻、剩余电量、用电量、单位
- 默认显示最近 20 条，支持展开/折叠全部
- 每 20 行高亮（周期性行标记，橙色背景）

### 空数据状态

数据文件格式：`data/electricity_data.json` 为 JSON Lines 格式，每行一个 JSON 对象，包含 `timestamp`、`remaining_electricity`、`unit` 字段。

当数据文件为空或无数据时：
- 显示 "暂无数据，等待下次采集..."
- 隐藏所有图表和表格

### 错误处理

- 数据加载失败时显示错误信息 + 重试按钮
- 网络错误时优雅降级
